# beraber06.github.io

Bu depo iki iş görür:

- `.well-known/assetlinks.json`: Yanlış Defterim Android paketinin (APK) siteyle eşleştiğini doğrular; böylece uygulama adres çubuğu olmadan tam ekran açılır. APK yeniden derlenirse buradaki imza (SHA-256) güncellenmelidir.
- `index.html`: kök adresi https://beraber06.github.io/yanlis-defterim/ adresine yönlendirir.

Uygulamanın kendisi: https://github.com/beraber06/yanlis-defterim
